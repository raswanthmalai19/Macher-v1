# Tech Support Scam Patterns

## Overview

Tech support scams involve fraudsters impersonating legitimate technology companies (Microsoft, Apple, Google, antivirus companies) to convince victims their computers are infected or compromised. They then charge for unnecessary services or gain remote access to steal personal information.

## Common Tactics

### Impersonation
- Claims to be from Microsoft, Apple, Google, or antivirus companies
- Uses official-sounding titles like "Senior Technician" or "Security Specialist"
- References real company names and products
- May display fake caller ID showing company names

### Fake Threats
- Claims computer is infected with viruses or malware
- Warns of security breaches or hacking attempts
- Reports suspicious activity on accounts
- Claims warranty or subscription is expiring
- Warns of imminent data loss or system failure

### Remote Access Requests
- Asks victim to install remote access software (TeamViewer, AnyDesk, LogMeIn)
- Requests permission to "diagnose" or "fix" the computer
- Shows fake error messages or system scans
- Demonstrates "proof" of infection using normal system files

### Payment Demands
- Charges for unnecessary technical support services
- Sells fake antivirus or security software
- Demands payment for "lifetime protection"
- Requests credit card information for "verification"
- Offers refunds that require bank account access

## Fraud Indicators

### High-Confidence Indicators (90-100% fraud likelihood)
- **Unsolicited calls about computer problems**: Legitimate companies don't call customers about computer issues
- **Remote access requests**: Legitimate support rarely requests remote access without prior authorization
- **Payment via gift cards or wire transfer**: Legitimate companies accept standard payment methods
- **Pressure to act immediately**: Legitimate support provides time to consider options

### Medium-Confidence Indicators (60-89% fraud likelihood)
- Claims of virus infection without prior contact
- Requests to visit specific websites or download software
- Aggressive sales tactics for security products
- Refusal to provide written documentation or callback numbers
- Claims of warranty expiration requiring immediate renewal

### Low-Confidence Indicators (30-59% fraud likelihood)
- Caller ID shows tech company name
- Use of technical jargon
- Reference to specific products or services
- Offers of free security scans

## Detection Guidelines

### Red Flags
1. **Unsolicited Contact**: Legitimate companies don't call about computer problems
2. **Remote Access**: Requests to install remote access software
3. **Urgency**: Immediate action required to prevent data loss
4. **Payment Method**: Gift cards, wire transfers, or cryptocurrency
5. **Fake Proof**: Showing normal system files as "viruses"

### Legitimate Tech Support
- Initiated by customer, not company
- Provides clear documentation and receipts
- Accepts standard payment methods
- Allows time for decision-making
- Never requests remote access without authorization

## Example Phrases

### High-Risk Phrases
- "Your computer is infected with viruses"
- "We detected suspicious activity on your account"
- "Your Windows license has expired"
- "Download this software to fix the problem"
- "I need remote access to your computer"
- "Pay now to prevent data loss"
- "Your warranty is expiring today"

### Medium-Risk Phrases
- "We're calling from Microsoft/Apple technical support"
- "Your computer is sending error messages"
- "We need to verify your account"
- "This is a courtesy call about your computer"
- "We can fix this problem for you"

## Refund Scam Variant

A common variant involves scammers claiming to offer refunds for previous tech support services:

### Tactics
- Claims company is going out of business
- Offers refund for previous services
- Requests bank account information to "process refund"
- "Accidentally" deposits too much money
- Demands victim return the "overpayment"
- Uses fake bank websites to show false balances

### Indicators
- Unsolicited refund offers
- Requests for bank account access
- Claims of overpayment requiring return
- Pressure to act quickly before "refund window closes"

## Confidence Scoring

When analyzing conversations for tech support scam indicators:

- **DANGER (67-100)**: Multiple high-confidence indicators present (remote access requests, payment demands, fake virus warnings)
- **CAUTION (34-66)**: Medium-confidence indicators present (unsolicited contact, urgency, technical jargon)
- **SAFE (0-33)**: Low or no fraud indicators detected

## Response Recommendations

### For DANGER Level
- Alert user immediately with haptic feedback
- Display clear warning: "SCAM DETECTED - Hang up immediately"
- Provide guidance: "Legitimate companies don't call about computer problems"
- Suggest actions: Hang up and contact company directly using official phone numbers

### For CAUTION Level
- Alert user with visual warning
- Display message: "Possible scam - Be cautious"
- Provide verification steps: "Hang up and call the company using official contact information"
- Remind: "Never give remote access to unsolicited callers"

### For SAFE Level
- Continue monitoring conversation
- No immediate alert required
- Log conversation for pattern analysis

## Prevention Tips

- Legitimate tech companies don't make unsolicited calls
- Never install software or grant remote access to unsolicited callers
- Don't trust caller ID - it can be spoofed
- Hang up and contact the company directly using official phone numbers
- Never pay for tech support with gift cards or wire transfers
